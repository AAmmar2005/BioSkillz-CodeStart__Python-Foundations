## 🚀 Getting Started

Follow these steps to run the assignments on your computer.

### 1. Install Python

Download Python from the official website:

[Python Official Website](https://www.python.org/downloads/)

Verify your installation:

```bash
python --version
```

On Windows, you can also use:

```bash
py --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/AAmmar2005/BioSkillz-CodeStart__Python-Foundations.git
```

### 3. Open the Project Folder

```bash
cd BioSkillz-CodeStart__Python-Foundations
```

### 4. Run an Assignment

To run Task 01:

```bash
python Ahmad_Ammar_task_01.py
```

To run Task 02:

```bash
python Ahmad_Ammar_task_02.py
```

On Windows, use `py` instead of `python` if needed.

**Note:** These are interactive programs. Enter the requested values in the terminal when prompted.
